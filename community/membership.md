# ✅ Adesão

## 🙋 Quem pode ser membro?

Qualquer elemento da comunidade do **Instituto Politécnico de Setúbal (IPS)** pode participar no ROOTS, incluindo:

* Estudantes
* Docentes
* Investigadores
* Funcionários não docentes
* *Alumni* (ex-alunos que já tenham sido membros - isto permite manter uma ligação aos projetos desenvolvidos);

O grupo promove a colaboração interdisciplinar e está aberto tanto a atividades de software como de hardware.

---

## 📝 Registo

Para integrar a comunidade ROOTS, é necessário preencher o formulário de adesão:

👉 **[Formulário de adesão](https://forms.office.com/e/EsZqadJWXu)**

Este registo serve para:

* Caracterizar o perfil do membro e unidade orgânica;
* Inserir o endereço na mailing list;
* Facilitar o processo de integração na organização GitHub.

> [!IMPORTANT]
> Para uma participação plena no grupo, é necessária uma conta Github (ver secção 3️⃣). No formulário de registo poderás incluir o teu *username*/email da conta para seres adicionado a esta organização do ROOTS.
>
> Se preencheste o formulário durante a divulgação inicial do grupo, poderás preenchê-lo novamente com esta informação ou então envia um email - através do teu email institucional - para o contacto na secção 7️⃣, fornecendo o username/email da tua conta Github.

---

## 🪪 Conta GitHub

O ROOTS utiliza o GitHub como principal plataforma de colaboração, gestão de discussões e desenvolvimento de projetos.

Para poder:

* Participar nos fóruns (GitHub Discussions);
* Contribuir para repositórios;
* Criar ou comentar issues, e/ou;
* Fazer parte de equipas de projeto.

é **necessária uma conta GitHub ativa**.

> [!TIP]
> 🎓 **Recomendação para estudantes**
>
> Como após a conclusão do curso deixas de ter acesso ao email institucional, recomenda-se que **cries a conta GitHub usando o teu email pessoal**, para garantir continuidade como membro *Alumni*.

### Perfil GitHub recomendado

Para facilitar a criação de equipas e a identificação de afinidades, sugere-se que a descrição do teu perfil GitHub inclua:

* **Áreas de interesse**

* **Competências técnicas**, em qualquer domínio relevante, tais como: desenvolvimento front-end, back-end ou full-stack; ciência de dados; automação; eletrónica e hardware; desenvolvimento mobile; administração de sistemas; redes; DevOps; segurança informática; ou qualquer outra área tecnológica com que te sintas confortável.

* **Competências não-técnicas**, que também são extremamente úteis para o funcionamento do grupo, como:

  * comunicação e escrita

  * marketing e divulgação

  * design gráfico

  * gestão de projetos

  * revisão e testing

  * organização de eventos

  * investigação e análise

O ROOTS valoriza contributos multidisciplinares, não é necessário ter “*hard-skills*” técnicas para participar ativamente. Cada competência conta!

---

## 🔑 Acesso à organização ROOTS no GitHub

Após criares a tua conta GitHub e preencheres o formulário:

➡️ **Irás receber brevemente um _invite_ para entrar na organização ROOTS.**

> [!NOTE]
> Este _invite_ seguirá na forma de email para o endereço que utilizaste para registar a tua conta Github.

Depois de aceite:

* Ganhas acesso às discussões internas;
* Podes comentar, propor ideias e participar nos projetos;
* Podes integrar equipas temáticas ou equipas de projetos específicos.

---

## 🤝 Leitura obrigatória: Código de Conduta

Antes de participares ativamente, é **obrigatório ler o [Código de Conduta](code-of-conduct.md) do ROOTS**.

Este documento define:

* Normas de comportamento;
* Expectativas de colaboração;
* Regras para interações presenciais e online;
* Como reportar incidentes.

O cumprimento destas regras é essencial para garantir um ambiente seguro, inclusivo, cordial e profissional.

---

## 🧘‍♂️ Participação e compromisso

A participação no ROOTS é **totalmente voluntária**.
Cada membro define o seu nível de envolvimento, mas espera-se:

* Respeito pelos colegas;
* Transparência e comunicação clara;
* Uso responsável dos recursos do grupo;
* Boa vontade em colaborar e aprender.

Não existem obrigações formais, mas a comunidade cresce com a participação ativa e consistente dos seus membros.
